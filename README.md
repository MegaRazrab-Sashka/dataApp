# Клиент PostgreSQL на Python + Qt

## Запуск
```
python -m venv venv
venv\Scripts\activate        # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Как устроена защита от SQL-инъекций
| Угроза | Защита |
|---|---|
| Инъекция через значения (`' OR 1=1 --`) | Значения передаются только как параметры `%s` (psycopg отправляет их серверу отдельно от текста запроса) |
| Инъекция через имена таблиц/столбцов | Проверка по белому списку из `information_schema` + `psycopg.sql.Identifier` |
| Инъекция через операторы / ORDER BY | Операторы берутся из фиксированного словаря, направление сортировки — константа |
| Произвольный SQL от пользователя | Не поддерживается: запрос собирается конструктором |
| Повреждение данных | Сессия `default_transaction_read_only=on`; в продакшене дополнительно используйте роль БД с правом только `SELECT` |
| Тяжёлые запросы | `statement_timeout` = 10 с, `LIMIT` ≤ 10 000 |

## Файлы
- `db.py` — подключение, метаданные, безопасное построение и выполнение запроса
- `main.py` — графический интерфейс (PySide6)
